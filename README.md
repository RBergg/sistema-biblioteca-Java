# Sistema de Biblioteca Java

Projeto desenvolvido com Java para simular o gerenciamento de uma biblioteca.

---

## Objetivo

Construir uma aplicação que permita cadastrar e consultar livros e leitores,
além de gerenciar empréstimos e devoluções.

## Funcionalidades planejadas

- Cadastro e consulta de livros.
- Cadastro e consulta de leitores.
- Controle de exemplares disponíveis.
- Registro de empréstimos.
- Registro de devoluções.
- Controle de prazos e bloqueio por atraso.

## Tecnologias

- Java 17
- Git e GitHub
